# 🚀 Starter Template

This is a clean, pre-configured starter for new UI integrations in this gallery.

## Features
- **Vite + React + TypeScript**
- **Tailwind CSS** pre-configured
- **Shared Components** integration ready
- **Optimized for Vercel** deployment

## Usage
1. Copy this folder to your desired category (e.g., `templates/landing-pages/my-new-page`).
2. Run `npm install` from the root.
3. Start development: `npm run dev`.
