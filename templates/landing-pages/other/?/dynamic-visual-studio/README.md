# Dynamic Visual Studio

A modern, dark-themed SaaS landing page.

## Features

- **Dynamic Design**: Indigo and dark gray palette with blur effects.
- **Components**: Studio preview, Features list, Community Showcase.
- **Routing**: Setup with `react-router-dom`.

## Getting Started

### Prerequisites

Node.js (v18+)

### Installation

1.  Navigate to the directory:
    ```bash
    cd dynamic-visual-studio
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run development server:
    ```bash
    npm run dev
    ```
