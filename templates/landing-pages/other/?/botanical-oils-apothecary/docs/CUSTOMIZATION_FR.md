# Guide de Personnalisation

Ce template est conçu pour être facilement personnalisé (white-label).

## 🎨 Branding (src/config/branding.ts)

Modifiez ce fichier pour l'identité de votre marque :
- **Nom du site**: `name`
- **Slogan**: `tagline`
- **Coordonnées**: Email, Téléphone, Adresse.
- **Réseaux Sociaux**: Liens Instagram, etc.

## 📝 Contenu (src/config/content.ts)

Modifiez ce fichier pour tout le contenu textuel :
- **Hero**: Titre, description, boutons.
- **Produits**: Ajoutez ou modifiez vos produits.
- **Trust Signals**: Modifiez les avantages affichés.
