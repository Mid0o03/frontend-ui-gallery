**Lumina Botanica** is a high-end, production-ready e-commerce template designed for boutique botanical shops, apothecaries, and luxury beauty brands. Built with React 19, Vite, and Tailwind CSS, it offers a seamless, performance-optimized shopping experience.

![Preview](https://images.unsplash.com/photo-1595981267035-7b04ca84a82d?auto=format&fit=crop&q=80&w=1200)

## ✨ Core Features

- 🌿 **Premium Design**: Sleek, modern aesthetics tailored for high-end botanical brands.
- 🏷️ **White-Label System**: Centralized branding and content configuration.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- 🎨 **Modern Tech Stack**: React 19, TypeScript, Vite, and Tailwind CSS.
- 🔍 **SEO Optimized**: Pre-configured meta tags, Open Graph, and semantic HTML.
- 🛒 **Interactive UI**: Dynamic product filtering, cart functionality, and hover effects.

## 🚀 Quick Start

1. **Clone & Install**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

## 🛠 Tech Stack

- **Framework**: React 19 (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: CSS Transitions & Framer Motion (optional/ready)
- **Routing**: React Router 7
