# Design Platform

A brutalist-style landing page for a design course platform.

## Features

- **Brutalist Design**: Bold typography and high contrast.
- **Components**: Stats strip, Course Grid, Newsletter.
- **Routing**: Setup with `react-router-dom`.

## Getting Started

### Prerequisites

Node.js (v18+)

### Installation

1.  Navigate to the directory:
    ```bash
    cd design-platform---brutalist-landing-page
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run development server:
    ```bash
    npm run dev
    ```
