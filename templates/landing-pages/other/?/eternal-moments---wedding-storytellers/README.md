# Eternal Moments - Wedding Storytellers

A romantic wedding photography portfolio template.

## Features

- **Elegant Design**: Soft colors, serif typography.
- **Components**: Testimonials Grid, CTA.
- **Routing**: Setup with `react-router-dom`.

## Getting Started

### Prerequisites

Node.js (v18+)

### Installation

1.  Navigate to the directory:
    ```bash
    cd eternal-moments---wedding-storytellers
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run development server:
    ```bash
    npm run dev
    ```
