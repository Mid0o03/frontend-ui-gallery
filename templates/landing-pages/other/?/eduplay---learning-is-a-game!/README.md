## 🚀 English

**EduPlay** is a premium, high-conversion landing page template designed specifically for educational platforms, mobile games, and learning apps. It features a vibrant, "candy-like" aesthetic with smooth 3D-inspired animations and a fully integrated AI Mascot Assistant.

### Key Features
- **Modern UI/UX**: Playful, responsive design using React and Tailwind CSS.
- **AI Mascot Assistant**: Pre-integrated 3D mascot (Oliver the Owl) using Google Gemini AI.
- **White-Label Configuration**: Centralized branding and content management for easy customization.
- **Performance Optimized**: Built with Vite for lightning-fast loading speeds.
- **Bilingual Documentation**: Comprehensive guides provided in both English and French.

### Caractéristiques principales
- **UI/UX Moderne**: Design ludique et réactif utilisant React et Tailwind CSS.
- **Assistant Mascotte IA**: Mascotte 3D pré-intégrée (Oliver le Hibou) utilisant l'IA Google Gemini.
- **Système de Marque Blanche**: Gestion centralisée du contenu et du branding pour une personnalisation facile.
- **Optimisé pour la Performance**: Construit avec Vite pour des vitesses de chargement ultra-rapides.
- **Documentation Bilingue**: Guides complets fournis en anglais et en français.
