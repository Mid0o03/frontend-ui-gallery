# Calm - Meditation & Mindfulness

A mobile-first, atmospheric meditation app template.

## Features

- **Atmospheric Design**: Aurora gradients and glassmorphism UI.
- **Mobile First**: Optimized for mobile viewports (max-width 480px).
- **Navigation**: Simple routing (`Home`, `Meditate`, `Benefits`).
- **Interactive**: Intention generator tool.

## Getting Started

### Prerequisites

Node.js (v18+)

### Installation

1.  Navigate to the directory:
    ```bash
    cd calm---meditation-&-mindfulness
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run development server:
    ```bash
    npm run dev
    ```

## Customization

- **Styles**: Animations and gradients in `index.css`.
- **Components**: Edit `components/` for UI changes.
