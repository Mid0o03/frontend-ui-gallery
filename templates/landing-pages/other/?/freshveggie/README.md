# FreshVeggie

A fresh vegetable delivery service template.

## Features

- **Engagement Section**: Highlight key value propositions.
- **Harvest Selection**: Product showcase.
- **Routing**: Setup with `react-router-dom`.

## Getting Started

### Prerequisites

Node.js (v18+)

### Installation

1.  Navigate to the directory:
    ```bash
    cd freshveggie
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run development server:
    ```bash
    npm run dev
    ```
