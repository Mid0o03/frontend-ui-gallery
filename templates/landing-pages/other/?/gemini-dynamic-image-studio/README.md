# Gemini Dynamic Image Studio

AI Image generation studio template.

## Features

- **Dynamic Image Studio**: Interactive demo.
- **Routing**: Setup with `react-router-dom`.

## Getting Started

### Prerequisites

Node.js (v18+)

### Installation

1.  Navigate to the directory:
    ```bash
    cd gemini-dynamic-image-studio
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run development server:
    ```bash
    npm run dev
    ```
