# Cabinet Professional Consulting

A modern, professional consulting cabinet template.

## Features

- **Professional Design**: Clean layout, distinct typography, authoritative look.
- **Routing**: Multi-page app structure (`Home`, `Approach`, `Space`, `Contact`).
- **Components**: Modular React components.

## Getting Started

### Prerequisites

Node.js (v18+)

### Installation

1.  Navigate to the directory:
    ```bash
    cd cabinet-professional-consulting
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run development server:
    ```bash
    npm run dev
    ```

## Customization

- **Fonts**: Check `tailwind.config.js` or CSS files for font definitions.
- **Components**: Edit files in `components/` to change the UI content.
