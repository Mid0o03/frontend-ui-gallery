# Glass Agency Landing Page

A modern agency landing page with glassmorphism effects.

## Features

- **Glassmorphism**: Visual style.
- **Services**: Service offering showcase.
- **Routing**: Setup with `react-router-dom`.

## Getting Started

### Prerequisites

Node.js (v18+)

### Installation

1.  Navigate to the directory:
    ```bash
    cd glassagency-landing-page
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run development server:
    ```bash
    npm run dev
    ```
