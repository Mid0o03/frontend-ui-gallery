# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-05-20

### Added
- **White-Label System**: Centralized configuration for branding (`branding.ts`) and content (`content.ts`).
- **Bilingual Documentation**: Comprehensive guides in English and French (README, INSTALLATION, CUSTOMIZATION, DEPLOYMENT).
- **SEO Optimization**: Meta tags, Open Graph, Twitter Cards, and semantic HTML structure.
- **AI Integration UI**: dedicated interface for "Bonsai Sensei" feature (UI only).
- **Gallery**: Dynamic gallery with smooth interactions.
- **Dark Mode**: Fully supported dark theme.
