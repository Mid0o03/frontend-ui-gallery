# Modern Art Exhibition - Template Portfolio Premium

Un template de portfolio haut de gamme et minimaliste conçu pour les expositions d'art, les galeries et les vitrines créatives. Construit avec React et Vanilla CSS (Tailwind via CDN pour la rapidité), ce template suit l'école de pensée du Swiss Design : précision, typographie et utilisation intentionnelle de l'espace.

[View English version (README.md)](./README.md)

## ✨ Fonctionnalités
- **Esthétique Swiss Design** : Minimalisme, typographie audacieuse et mises en page efficaces.
- **Entièrement Responsif** : Optimisé pour bureau, tablette et mobile.
- **Prêt pour le White-Label** : Configuration centralisée pour le branding et le contenu.
- **Optimisé SEO** : Meta tags, Open Graph et Twitter Cards inclus.
- **Animations Premium** : Effets de survol fluides et transitions d'entrée.
- **Type-Safe** : Développé avec TypeScript pour une meilleure maintenabilité.

## 🚀 Démarrage Rapide
1. **Cloner ou Télécharger** le projet.
2. **Installer les dépendances** :
   ```bash
   npm install
   ```
3. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```
4. **Build pour la production** :
   ```bash
   npm run build
   ```

## 🛠️ Stack Technique
- **Framework** : React 19
- **Styling** : Tailwind CSS (CDN)
- **Infrastructure** : Vite
- **Langage** : TypeScript
