# Template Landing Page BentoGrid SaaS 🚀

Un template de landing page SaaS premium à haute conversion avec un design moderne de type "Bento Grid". Construit avec **React 19**, **Tailwind CSS**, et pré-intégré avec **Supabase Auth** et **Stripe Payments**.

## ✨ Fonctionnalités

- 🍱 **Grid Style Bento**: Mise en page moderne et visuellement impressionnante.
- ⚡ **Ultra Rapide**: Construit avec Vite pour un HMR instantané et des builds optimisés.
- 🔐 **Supabase Ready**: Authentification pré-intégrée (Connexion/Inscription).
- 💳 **Intégration Stripe**: Page de tarification prête pour le Checkout.
- 📱 **Entièrement Responsive**: Optimisé pour Mobile, Tablette et Desktop.
- 🎨 **White-Label**: Configuration centralisée pour le branding et le contenu.
- 📈 **Optimisé SEO**: Meta tags, Open Graph et Twitter cards inclus.

## 🛠️ Stack Technique

- **Frontend**: React 19, TypeScript, Tailwind CSS
- **Backend/Auth**: Supabase
- **Paiements**: Stripe
- **Icônes**: Material Symbols Outlined
- **Polices**: Space Grotesk (Google Fonts)

## 🏁 Démarrage Rapide

1. **Cloner le repository**
2. **Installer les dépendances**
   ```bash
   npm install
   ```
3. **Configurer les variables d'environnement**
   Copiez `.env.example` en `.env` et remplissez vos clés Supabase et Stripe.
   ```bash
   cp .env.example .env
   ```
4. **Lancer le serveur de développement**
   ```bash
   npm run dev
   ```
