# GrowthMastery - Template de Landing Page Premium

GrowthMastery est un template de landing page à haute conversion conçu avec React, Vite et Tailwind CSS. Il est idéal pour les créateurs de cours, les éducateurs et les marketeurs digitaux qui souhaitent vendre leur expertise avec un look professionnel et premium.

## 🚀 Caractéristiques Clés

- **Esthétique Premium** : Design moderne avec glassmorphism, dégradés lisses et micro-animations.
- **Système White-Label** : Configuration centralisée pour le branding et le contenu.
- **Entièrement Responsive** : Optimisé pour desktop, tablette et mobile.
- **Optimisé SEO** : Balises meta pré-configurées pour les moteurs de recherche et le partage social.
- **Mode Sombre/Clair** : Transitions fluides entre les thèmes sombre et clair.
- **Personnalisable** : Changement facile des couleurs, polices et images via un seul fichier de config.

## 🛠 Stack Technique

- **Framework** : [React 19](https://react.dev/)
- **Outil de Build** : [Vite 6](https://vitejs.dev/)
- **Styling** : [Tailwind CSS](https://tailwindcss.com/) (via CDN pour simplifier l'installation)
- **Langage** : [TypeScript](https://www.typescriptlang.org/)
- **Icônes** : [Google Material Symbols](https://fonts.google.com/icons)
- **Typographie** : [Google Fonts (Manrope & Noto Sans)](https://fonts.google.com/)

## ⚡ Démarrage Rapide

1. **Cloner le projet** :
   ```bash
   git clone https://github.com/votre-repo/growthmastery-landing-page.git
   ```

2. **Installer les dépendances** :
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```

4. **Build pour la production** :
   ```bash
   npm run build
   ```
