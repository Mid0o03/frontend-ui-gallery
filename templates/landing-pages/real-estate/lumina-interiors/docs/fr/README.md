Un template React premium et hautement raffiné conçu pour les studios de design d'intérieur, les architectes et les portfolios créatifs. Construit avec React et Tailwind CSS, mettant l'accent sur une typographie élégante, des interactions fluides et une esthétique luxueuse.

## 🌟 Caractéristiques

*   **Design Élégant et Intemporel** : Conçu avec un accent sur le luxe et l'espace négatif.
*   **Entièrement Responsif** : Expérience parfaite sur tous les appareils.
*   **Interactions Fluides** : Animations subtiles et effets de défilement.
*   **Architecture White-Label** : Personnalisation facile via `config/branding.ts` et `config/content.ts`.
*   **Stack Technique Moderne** : React, Vite, Tailwind CSS.
*   **Optimisé SEO** : HTML sémantique et bonnes pratiques.

## 🚀 Démarrage Rapide

1.  **Installer les dépendances** :
    ```bash
    npm install
    ```

2.  **Lancer le serveur de développement** :
    ```bash
    npm run dev
    ```

3.  **Compiler pour la production** :
    ```bash
    npm run build
    ```

## 🛠 Stack Technique

*   **Framework** : React (Vite)
*   **Style** : Tailwind CSS (CDN ou PostCSS)
*   **Icônes** : Material Symbols Outlined
*   **Polices** : Spline Sans (Display), Playfair Display (Serif)

## 📁 Structure du Projet

```
lumina-interiors/
├── components/      # Composants UI (Hero, Portfolio, etc.)
├── config/          # Fichiers de configuration (branding.ts, content.ts)
├── App.tsx          # Composant principal de l'application
├── index.tsx        # Point d'entrée
├── index.html       # Point d'entrée HTML
└── docs/            # Documentation multilingue
```
