A premium, highly-polished React template designed for interior design studios, architects, and creative portfolios. Built with React and Tailwind CSS, focusing on elegant typography, smooth interactions, and a luxurious aesthetic.

## 🌟 Features

*   **Elegant & Timeless Design**: Crafted with a focus on luxury and negative space.
*   **Fully Responsive**: Flawless experience across all devices.
*   **Smooth Interactions**: Subtle animations and scroll effects.
*   **White-Label Architecture**: Easy customization via `config/branding.ts` and `config/content.ts`.
*   **Modern Tech Stack**: React, Vite, Tailwind CSS.
*   **SEO Optimized**: Semantic HTML and best practices.

## 🚀 Quick Start

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Start development server**:
    ```bash
    npm run dev
    ```

3.  **Build for production**:
    ```bash
    npm run build
    ```

## 🛠 Tech Stack

*   **Framework**: React (Vite)
*   **Styling**: Tailwind CSS (CDN or PostCSS)
*   **Icons**: Material Symbols Outlined
*   **Fonts**: Spline Sans (Display), Playfair Display (Serif)

## 📁 Project Structure

```
lumina-interiors/
├── components/      # UI Components (Hero, Portfolio, etc.)
├── config/          # Configuration files (branding.ts, content.ts)
├── App.tsx          # Main application component
├── index.tsx        # Entry point
├── index.html       # HTML entry point
└── docs/            # Multilingual documentation
```
