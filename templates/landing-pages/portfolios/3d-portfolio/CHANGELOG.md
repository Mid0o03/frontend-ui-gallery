- White-label configuration system (`config/branding.ts`, `config/content.ts`).
- Responsive design for Mobile, Tablet, and Desktop.
- Claymorphism UI style with Tailwind CSS.
- Interactive 3D-like animations using CSS transforms.
- Dark mode support (system preference based).
