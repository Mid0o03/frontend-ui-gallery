# Template Portfolio 3D

![Bannière](https://via.placeholder.com/1200x600?text=Template+Portfolio+3D)

Un template de portfolio premium, interactif et responsive conçu pour les artistes 3D, illustrateurs et professionnels créatifs. Construit avec **React**, **Vite**, et **Tailwind CSS**.

## Fonctionnalités

- **Éléments 3D Interactifs** : Animations flottantes ludiques et style "Claymorphism".
- **Design Responsive** : S'adapte parfaitement aux mobiles, tablettes et ordinateurs.
- **Configuration White-Label** : Modifiez facilement le contenu, l'image de marque et les couleurs via un fichier de configuration simple.
- **Performance Optimisée** : Chargement rapide avec Vite.
- **Prêt pour le SEO** : Balises Meta et support Open Graph inclus.
- **Support Mode Sombre** : S'adapte automatiquement aux préférences système.

## Stack Technique

- [React](https://reactjs.org/) (v18)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)

## Démarrage Rapide

1.  **Installer les dépendances** :
    ```bash
    npm install
    ```
2.  **Lancer le serveur de développement** :
    ```bash
    npm run dev
    ```
3.  **Construire pour la production** :
    ```bash
    npm run build
    ```
