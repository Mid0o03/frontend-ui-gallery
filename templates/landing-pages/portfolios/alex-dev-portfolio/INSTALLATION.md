# Installation Guide / Guide d'Installation

## English

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Steps
1.  **Unzip the file** to your desired folder.
2.  **Open terminal** in that folder.
3.  **Install dependencies**:
    ```bash
    npm install
    # or
    yarn install
    ```
4.  **Start development server**:
    ```bash
    npm run dev
    # or
    yarn dev
    ```
5.  Open [http://localhost:5173](http://localhost:5173) (or the port shown in terminal) to view the site.

### Troubleshooting
- **Build fails?** Check if you have the latest Node.js version.
- **Styles missing?** Ensure Tailwind CSS is building correctly (`npm run dev` handles this).

## Français

### Prérequis
- Node.js (v16 ou supérieur)
- npm ou yarn

### Étapes
1.  **Décompressez le fichier** dans le dossier de votre choix.
2.  **Ouvrez un terminal** dans ce dossier.
3.  **Installez les dépendances** :
    ```bash
    npm install
    # ou
    yarn install
    ```
4.  **Lancez le serveur de développement** :
    ```bash
    npm run dev
    # ou
    yarn dev
    ```
5.  Ouvrez [http://localhost:5173](http://localhost:5173) pour voir le site.

### Dépannage
- **Échec du build ?** Vérifiez que vous avez une version récente de Node.js.
- **Styles manquants ?** Assurez-vous que Tailwind CSS se compile bien.
