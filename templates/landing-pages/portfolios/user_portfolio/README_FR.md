# PortfolioOS - Template de Portfolio Terminal Premium

PortfolioOS est un template de portfolio haut de gamme inspiré d'un terminal, conçu pour les développeurs, les architectes système et les passionnés de technologie. Il présente un effet de superposition CRT unique, une interface terminal fonctionnelle et une esthétique moderne et épurée.

## 🚀 Caractéristiques

- **UI Unique**: Interface de style terminal avec une superposition de lignes de balayage CRT.
- **Entièrement Responsif**: Optimisé pour les ordinateurs de bureau et les appareils mobiles.
- **Prêt pour le White-Label**: Configuration centralisée pour le branding et le contenu.
- **Stack Technique Moderne**: Construit avec React, TypeScript et Tailwind CSS.
- **Éléments Interactifs**: Formulaire de contact fonctionnel et explorateur de projets.
- **Optimisé pour le SEO**: Méta-tags pré-configurés et support Open Graph.

## 🛠️ Stack Technique

- **Framework**: React 18
- **Langage**: TypeScript
- **Styling**: Tailwind CSS
- **Icônes**: Lucide React
- **Outil de Build**: Vite

## ⏱️ Démarrage Rapide

1. **Cloner le dépôt**:
   ```bash
   git clone <votre-url-repo>
   cd user_portfolio
   ```

2. **Installer les dépendances**:
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement**:
   ```bash
   npm run dev
   ```

4. **Compiler pour la production**:
   ```bash
   npm run build
   ```
