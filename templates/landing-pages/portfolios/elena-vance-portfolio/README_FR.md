# Elena Vance Portfolio - Template de Photographie

Un template de portfolio de photographie premium à défilement horizontal, conçu pour les photographes, artistes et créateurs qui recherchent une présence en ligne minimaliste et cinématographique.

## ✨ Fonctionnalités

- **Expérience de Défilement Horizontal** : Une façon unique et immersive de présenter vos travaux visuels.
- **Mises en Page Cinématographiques** : Des portraits en plein écran aux collections en grille élégantes.
- **Système White-Label** : Personnalisez facilement le branding et le contenu via des fichiers de configuration dédiés.
- **Entièrement Responsive** : Optimisé pour ordinateurs, tablettes et mobiles.
- **Stack Technique Moderne** : Construit avec React 19, Vite et Tailwind CSS.
- **Optimisé SEO** : Balises méta pré-configurées pour les moteurs de recherche et le partage social.

## 🚀 Démarrage Rapide

1. **Cloner le projet** :
   ```bash
   git clone <url-du-repo>
   cd elena-vance-portfolio
   ```

2. **Installer les dépendances** :
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```

4. **Générer le build de production** :
   ```bash
   npm run build
   ```

## 🛠 Stack Technique
