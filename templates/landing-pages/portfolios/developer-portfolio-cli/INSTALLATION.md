# 🛠 Installation Guide / Guide d'Installation

[English](#english) | [Français](#français)

---

## English

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Steps
1. **Extract the ZIP file**: Unzip the template to your desired directory.
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Environment setup**: Create a `.env.local` file if needed (see `.env.example`).
4. **Run locally**:
   ```bash
   npm run dev
   ```
5. **Production build**:
   ```bash
   npm run build
   ```

### Troubleshooting
- **Node version error**: Ensure you are using a compatible Node.js version.
- **Styles not loading**: Check if Tailwind is correctly initialized and if `index.css` is imported.

## Français

### Prérequis
- Node.js (v18 ou supérieur)
- npm ou yarn

### Étapes
1. **Extraire le fichier ZIP**: Décompressez le template dans le répertoire de votre choix.
2. **Installer les dépendances**:
   ```bash
   npm install
   ```
3. **Configuration de l'environnement**: Créez un fichier `.env.local` si nécessaire.
4. **Lancer localement**:
   ```bash
   npm run dev
   ```
5. **Build de production**:
   ```bash
   npm run build
   ```

### Dépannage
- **Erreur de version Node**: Vérifiez que vous utilisez une version compatible de Node.js.
- **Styles non chargés**: Vérifiez que Tailwind est correctement initialisé et que `index.css` est importé.
