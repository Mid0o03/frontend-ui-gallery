# 🎨 Customization Guide / Guide de Personnalisation

[English](#english) | [Français](#français)

---

## English

This template uses a centralized configuration system to make customization easy and fast.

### 1. Branding (`config/branding.ts`)
Update this file to change:
- Site name and tagline.
- Contact email.
- Social media links (GitHub, LinkedIn, Twitter).
- SEO metadata (Title, Description, Keywords).

### 2. Content (`config/content.ts`)
Update this file to change:
- Hero section text and system status messages.
- Statistics in the stats grid.
- Project list (paths, descriptions, icons).
- Skills list.
- Contact form labels and button text.
- Footer copyright and status.

### 3. Contact Email
The template is pre-configured with the contact email: `contact@midodev.fr`.

## Français

Ce template utilise un système de configuration centralisé pour rendre la personnalisation facile et rapide.

### 1. Branding (`config/branding.ts`)
Mettez à jour ce fichier pour modifier :
- Le nom du site et le slogan.
- L'email de contact.
- Les liens vers les réseaux sociaux (GitHub, LinkedIn, Twitter).
- Les métadonnées SEO (Titre, Description, Mots-clés).

### 2. Contenu (`config/content.ts`)
Mettez à jour ce fichier pour modifier :
- Le texte de la section Hero et les messages de statut système.
- Les statistiques dans la grille de stats.
- La liste des projets (chemins, descriptions, icônes).
- La liste des compétences.
- Les libellés du formulaire de contact et le texte du bouton.
- Le copyright et le statut du footer.

### 3. Email de Contact
Le template est pré-configuré avec l'email de contact : `contact@midodev.fr`.
