# 🚀 Deployment Guide / Guide de Déploiement

[English](#english) | [Français](#français)

---

## English

### Vercel (Recommended)
1. Push your code to GitHub/GitLab/Bitbucket.
2. Connect your repository to Vercel.
3. Vercel will automatically detect Vite and deploy your site.

### Netlify
1. Drag and drop the `dist` folder into Netlify Drop.
2. Or connect your repository for automatic builds.

### GitHub Pages
1. Install `gh-pages` package: `npm install gh-pages --save-dev`.
2. Add deploy script to `package.json`.
3. Run `npm run deploy`.

---

## Français

### Vercel (Recommandé)
1. Poussez votre code sur GitHub/GitLab/Bitbucket.
2. Connectez votre dépôt à Vercel.
3. Vercel détectera automatiquement Vite et déploiera votre site.

### Netlify
1. Glissez-déposez le dossier `dist` dans Netlify Drop.
2. Ou connectez votre dépôt pour des builds automatiques.

### GitHub Pages
1. Installez le paquet `gh-pages`: `npm install gh-pages --save-dev`.
2. Ajoutez le script de déploiement dans `package.json`.
3. Lancez `npm run deploy`.
