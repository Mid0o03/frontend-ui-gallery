## [1.0.0] - 2026-02-08

### Ajouté
- Sortie initiale du template Retro Vintage Store.
- Interface utilisateur responsive inspirée de Windows 95 / Vaporwave.
- Système de configuration white-label (`config/branding.ts`, `config/content.ts`).
- Documentation professionnelle en Anglais et Français.
- Barre de tâches interactive avec horloge en temps réel.
- Composants rétro: Window, DesktopIcon, ProductCard, HeroSection.
- Balises méta optimisées pour le SEO et support Open Graph.
