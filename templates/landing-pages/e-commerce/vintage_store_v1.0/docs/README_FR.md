# 📟 Template Retro Vintage Store

Un template e-commerce premium et hautement unique, inspiré par l'esthétique **Windows 95** et **Vaporwave**. Parfait pour les marques de vêtements vintage, les collections rétro ou toute marque cherchant une présence numérique remarquable.

## ✨ Caractéristiques Clés

- 🖥️ **Interface Style OS Unique**: Fenêtres, barres de tâches et boutons inspirés de Windows 95.
- 🌈 **Esthétique Vaporwave**: Couleurs néon, dégradés et motifs rétro-futuristes.
- 📱 **Entièrement Responsive**: Fonctionne parfaitement sur mobile, tablette et bureau.
- ⚙️ **Système de Configuration White-Label**: Gestion centralisée de la marque et du contenu.
- 🔍 **Optimisé SEO**: Balises méta, Open Graph et Twitter Cards pré-configurés.
- ⚡ **Performance Élevée**: Construit avec React 19, Vite et Tailwind CSS.
- 📂 **Code Source Organisé**: Propre, bien commenté et facile à maintenir.

## 🛠️ Stack Technique

- **Framework**: [React 19](https://react.dev/)
- **Outil de Build**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icônes**: [Lucide React](https://lucide.dev/)
- **Langage**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 Démarrage Rapide

1. **Installer les dépendances**:
   ```bash
   npm install
   ```

2. **Lancer en mode développement**:
   ```bash
   npm run dev
   ```

3. **Générer le build de production**:
   ```bash
   npm run build
   ```
