# 📝 Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-08

### Added
- Initial release of the Retro Vintage Store template.
- Fully responsive Windows 95 / Vaporwave inspired UI.
- White-label configuration system (`config/branding.ts`, `config/content.ts`).
- Professional documentation in English and French.
- Interactive Taskbar with live clock.
- Retro components: Window, DesktopIcon, ProductCard, HeroSection.
- SEO optimized meta tags and Open Graph support.
