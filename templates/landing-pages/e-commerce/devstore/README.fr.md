# DevStore - Template de Landing Page Commerciale

DevStore est un template de landing page premium à fort taux de conversion, conçu spécifiquement pour les développeurs, les freelances et les vendeurs de produits numériques. Construit avec React et Tailwind CSS, il présente un design moderne, un code propre et un système de configuration centralisé pour une personnalisation rapide (white-label).

## 🚀 Caractéristiques Clés

- **Design Premium** : Mise en page moderne, responsive et esthétique.
- **Prêt pour le White-Label** : Configuration centralisée du branding et du contenu dans `config/`.
- **Optimisé SEO** : Balises méta, tags OG et cartes Twitter pré-configurés.
- **Performances Rapides** : Configuration légère utilisant Vite et Tailwind (CDN ou npm).
- **Sections de Services** : Présentation des services intégrée et formulaires de contact.
- **Galerie** : Grille d'affichage professionnelle pour templates/produits.

## 🛠 Technologies Utilisées

- **React 19** : Développement d'interface moderne.
- **Tailwind CSS** : Stylisation utilitaire.
- **TypeScript** : Développement sécurisé par typage.
- **Vite** : Outil de build ultra-rapide.

## ⏱ Démarrage Rapide

1. **Cloner et Installer** :
   ```bash
   npm install
   ```

2. **Lancer le Serveur de Développement** :
   ```bash
   npm run dev
   ```

3. **Compiler pour la Production** :
   ```bash
   npm run build
   ```
