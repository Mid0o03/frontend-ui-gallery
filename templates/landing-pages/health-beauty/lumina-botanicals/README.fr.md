# 🌿 Lumina Botanicals - Template Landing Page Premium

Lumina Botanicals est un template de landing page haut de gamme et responsive, conçu pour les marques de soins, de beauté et de bien-être. Il propose un design moderne, une configuration centralisée pour une personnalisation facile (white-label) et une optimisation SEO.

## ✨ Caractéristiques Principales

- 💎 **Esthétique Moderne** : Glassmorphism, typographie soignée et transitions fluides.
- ⚙️ **Prêt pour le White-Label** : Configuration centralisée de l'image de marque et du contenu.
- 📱 **Entièrement Responsive** : Optimisé pour ordinateurs, tablettes et mobiles.
- 🚀 **Performance Optimisée** : Construit avec React et Vite pour des temps de chargement ultra-rapides.
- 🔍 **Optimisé SEO** : Balises meta, Open Graph et Twitter Cards pré-configurés.

## 🛠 Stack Technique

- **React 19** : Bibliothèque UI moderne.
- **Vite** : Outil de build et serveur de développement ultra-rapide.
- **Tailwind CSS** : Framework CSS utilitaire pour un stylage rapide.
- **TypeScript** : Développement typé et sécurisé.

## 🏁 Démarrage Rapide

1. **Installation** :
   ```bash
   npm install
   ```

2. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```

3. **Build de Production** :
   ```bash
   npm run build
   ```
