**L'Éclat d'Or** est un template de landing page haut de gamme pour institut de beauté, conçu avec une esthétique minimaliste et sophistiquée. Optimisé pour la conversion et la performance, il propose des animations fluides, un design adaptatif et un système de configuration "white-label" complet.

## ✨ Fonctionnalités

- **Esthétique de Luxe** : Design soigné avec une typographie premium et une palette de couleurs raffinée.
- **Ultra-Rapide** : Développé avec Vite et React pour des temps de chargement quasi instantanés.
- **Entièrement Personnalisable** : Configuration centralisée dans `/config` pour changer la marque et le contenu en quelques secondes.
- **Optimisé SEO** : Balises meta pré-configurées pour Google, Facebook et Twitter.
- **Responsive** : Affichage parfait sur mobile, tablette et ordinateur.
- **Stack Moderne** : React 19, Tailwind CSS et optimisation des ressources.

## 🚀 Démarrage Rapide

1. **Installer les dépendances** :
   ```bash
   npm install
   ```

2. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```

3. **Compiler pour la production** :
   ```bash
   npm run build
   ```
