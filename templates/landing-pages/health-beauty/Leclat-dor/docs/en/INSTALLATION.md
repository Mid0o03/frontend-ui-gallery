Follow these steps to set up the **L'Éclat d'Or** landing page on your local machine.

## Prerequisites

- **Node.js**: Version 18.0 or higher.
- **npm** or **yarn**: Integrated with Node.js.

## Step 1: Clone or Unzip
If you received this as a zip file, extract it to your desired folder.

## Step 2: Install Dependencies
Open your terminal in the project directory and run:

```bash
npm install
```

## Step 3: Run the Development Server
Launch the project in development mode with hot-reload:

```bash
npm run dev
```
The site should now be accessible at `http://localhost:5173`.

## Step 4: Production Build
To create an optimized version for production:

```bash
npm run build
```
This will generate a `dist/` folder containing all the static files needed for your web server.
