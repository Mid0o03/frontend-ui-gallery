# Changelog

All notable changes to the Beauty's Gold template will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-02-07

### Added
- Initial release of Beauty's Gold template
- Premium dark mode design with gold accents
- Fully responsive layout (mobile, tablet, desktop)
- GSAP animations (fade in, stagger, scroll-triggered, parallax)
- React 19 + TypeScript + Vite setup
- Tailwind CSS with custom configuration
- Custom animation hooks (`useGsapFadeIn`, `useGsapStagger`, etc.)
- Centralized branding configuration (`config/branding.ts`)
- Centralized content configuration (`config/content.ts`)
- SEO optimization (meta tags, Open Graph, Twitter cards)
- React Router for navigation
- Components:
  - Navbar with scroll effects
  - Hero section with parallax background
  - Philosophy section
  - Services grid
  - Contact section
  - Footer
- Documentation:
  - README.md
  - INSTALLATION.md
  - CUSTOMIZATION.md
  - ANIMATIONS.md
  - DEPLOYMENT.md
  - LICENSE
- White-label ready with easy rebranding

### Technical Details
- React 19.2.4
- TypeScript 5.8.3
- Vite 6.0.11
- Tailwind CSS 4.0.14
- GSAP 3.12.8
- React Router DOM 7.1.3
