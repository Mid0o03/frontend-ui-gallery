# Deployment Guide / Guide de Déploiement

## English

### Vercel / Netlify / Cloudflare Pages

1.  Connect your repository.
2.  Framework Preset: **Vite**.
3.  Build Command: `npm run build`.
4.  Output Directory: `dist`.
5.  Deploy!

### Traditional Hosting (FTP/cPanel)

1.  Run `npm run build` locally.
2.  Upload the contents of the `dist` folder to your server's `public_html` or equivalent.

---

## Français

### Vercel / Netlify / Cloudflare Pages

1.  Connectez votre dépôt.
2.  Framework Preset : **Vite**.
3.  Commande de Build : `npm run build`.
4.  Dossier de Sortie : `dist`.
5.  Déployez !

### Hébergement Traditionnel (FTP/cPanel)

1.  Lancez `npm run build` localement.
2.  Téléversez le contenu du dossier `dist` sur votre serveur dans `public_html` ou équivalent.
