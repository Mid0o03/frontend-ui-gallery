# Installation Guide / Guide d'Installation

## English

1.  **Install dependencies**:
    ```bash
    npm install
    ```
2.  **Start dev server**:
    ```bash
    npm run dev
    ```
3.  **Build for production**:
    ```bash
    npm run build
    ```

---

## Français

1.  **Installer les dépendances** :

2.  **Lancer le serveur de dev** :
