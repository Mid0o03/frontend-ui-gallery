# Customization Guide / Guide de Personnalisation

## English

### White-label System
This template uses a configuration system to make customization easy.

1.  **Branding**: Edit `config/branding.ts` to change the agency name, logo text, email, phone, address, and social links.
2.  **Content**: Edit `config/content.ts` to change the text content for the Navbar, Hero, Services, Works, Contact, and Footer sections.

### Styling
- **Tailwind CSS**: The project uses Tailwind CSS. You can customize the theme in `tailwind.config.js`.
- **Colors**: The primary colors are defined in `tailwind.config.js` (`primary`, `background-light`, `background-dark`). Change them there to update the look instantly.
- **Fonts**: We use `Spline Sans` (display) and `Noto Sans` (body) from Google Fonts. You can change them in `index.html` and `tailwind.config.js`.

## Français

### Système Marque Blanche
Ce modèle utilise un système de configuration pour faciliter la personnalisation.

1.  **Branding** : Modifiez `config/branding.ts` pour changer le nom de l'agence, le texte du logo, l'email, le téléphone, l'adresse et les réseaux sociaux.
2.  **Contenu** : Modifiez `config/content.ts` pour changer le texte des sections Navbar, Hero, Services, Works, Contact et Footer.

### Styles
- **Tailwind CSS** : Le projet utilise Tailwind CSS. Vous pouvez personnaliser le thème dans `tailwind.config.js`.
- **Couleurs** : Les couleurs primaires sont définies dans `tailwind.config.js` (`primary`, `background-light`, `background-dark`). Changez-les là pour modifier l'apparence instantanément.
- **Polices** : Nous utilisons `Spline Sans` (titres) et `Noto Sans` (corps) de Google Fonts. Vous pouvez les changer dans `index.html` et `tailwind.config.js`.
