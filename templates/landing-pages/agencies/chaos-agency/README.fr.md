# ⚡ Chaos Agency - Template Premium pour Agence Créative

Chaos Agency est un template de landing page à fort impact, conçu pour les studios de création, les agences de branding et les freelances audacieux. Avec son esthétique "Néo-Brutaliste", il est conçu pour capter l'attention et convertir vos visiteurs en clients.

## ✨ Caractéristiques

- **🎯 Design Disruptif** : Esthétique néo-brutaliste avec une typographie grasse et des couleurs contrastées.
- **📱 Entièrement Responsive** : Optimisé pour mobile, tablette et bureau.
- **⚙️ Prêt pour le White-Label** : Configuration centralisée pour le branding et le contenu.
- **🚀 Ultra Rapide** : Construit avec Vite et React pour des temps de chargement instantanés.
- **🎨 UI Néo-Brutaliste** : Ombres, bordures et animations personnalisées.
- **Optimisé SEO** : Meta tags, tags OG et cartes Twitter standardisés.
- **Code Propre** : Composants React bien organisés et TypeScript.

## 🛠 Stack Technique

- **Framework** : [React 19](https://react.dev/)
- **Outil de Build** : [Vite](https://vitejs.dev/)
- **Style** : [Tailwind CSS](https://tailwindcss.com/)
- **Icônes** : [Material Symbols Outlined](https://fonts.google.com/icons)
- **Typographie** : [Spline Sans](https://fonts.google.com/specimen/Spline+Sans)

## 🚀 Démarrage Rapide

1. **Cloner le dépôt** :
   ```bash
   git clone <votre-url-repo>
   cd chaos-agency
   ```

2. **Installer les dépendances** :
   ```bash
   npm install
   ```

3. **Lancer en mode développement** :
   ```bash
   npm run dev
   ```

4. **Build pour la production** :
   ```bash
   npm run build
   ```
