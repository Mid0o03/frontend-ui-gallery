## 🎯 About this repository
Instead of creating a new repository for every small design integration, I decided to group my frontend templates here. This allows me to keep my GitHub profile clean and provides a centralized showcase of my UI/UX integration skills.

## 📂 Project Structure

- **assets/** : Images, icons and shared fonts.
- **components/** : Reusable UI elements.
    - `basic/` : Buttons, badges, labels.
    - `forms/` : Inputs, checkboxes, selects.
    - `layouts/` : Containers, grids, spacers.
    - `navigation/` : Navbars, sidebars, tabs.
- **templates/** : Complete layouts and project starters.
    - `landing-pages/` : Homepages and showcases.
    - `dashboards/` : Admin interfaces.
    - `auth/` : Login and signup pages.
- **designs/** : UI/UX mockups and screenshots.
- **docs/** : Documentation and usage guides.
